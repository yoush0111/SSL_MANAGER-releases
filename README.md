# SSL Manager

외부에서 받은 SSL 인증서 파일(PEM/JKS)을 여러 서버에 SSH로 배포하고, 각 도메인의 443 포트로 실제 적용된 인증서의 만료일을 확인하는 Windows 데스크톱 앱입니다.

이 저장소는 **설치 파일 배포 전용**입니다. 앱의 자동 업데이트도 이 저장소의 [Releases](../../releases)를 확인합니다.

## 설치

[Releases](../../releases/latest)에서 원하는 파일을 내려받습니다.

| 파일 | 설명 |
|---|---|
| `ssl-manager-x.y.z-setup.exe` | **권장.** 설치형. 새 버전이 나오면 자동으로 업데이트됩니다. |
| `ssl-manager-x.y.z-portable.exe` | 설치 없이 실행. 자동 업데이트는 되지 않고 새 버전 안내만 표시됩니다. |

코드 서명을 하지 않은 빌드라 처음 실행할 때 Windows SmartScreen 경고가 나올 수 있습니다. **추가 정보 → 실행**을 누르세요.

## 기본 사용법

### 1. 서버 등록 (서버 탭)
1. 그룹(선택), 서버 이름, 호스트/IP, SSH 포트, SSH 계정을 입력합니다.
2. **인증서 설치 경로**: 서버에서 인증서 파일을 둘 폴더 (예: `/etc/nginx/ssl`)
3. **재시작 명령어**: 배포 후 실행할 명령 (예: `sudo systemctl reload nginx`)
   - `sudo`를 쓰려면 서버에 해당 명령의 NOPASSWD sudo 설정이 필요합니다.
4. **서버 타입**: NGINX / TOMCAT_PEM / TOMCAT_JKS
5. **접속 방식**
   - **키 파일**: SSH 개인키 파일을 선택합니다. 키는 암호화되어 저장됩니다.
   - **ID/PW**: 비밀번호는 처음 배포하거나 [접속 테스트]를 할 때 입력하며, 로그인에 성공했을 때만 암호화되어 저장됩니다.
6. [저장] 후 [접속 테스트]로 연결을 확인합니다. 첫 접속 때 서버의 호스트 키가 등록됩니다.

### 2. 인증서 등록 (인증서 탭)
- **폴더에서 찾기**: 인증서 파일이 있는 폴더를 고르면 파일 내용으로 인증서·개인키·chain을 구분해 후보를 보여 줍니다. 체크한 것만 등록됩니다.
- **직접 선택**: 형식(PEM/JKS)을 고르고 파일을 하나씩 선택합니다.
  - PEM: 인증서, 개인키, chain(선택)
  - JKS: jks 파일 하나
- 인증서 이름은 인증서 파일명으로 정해지며, 서버에도 **PC 파일명 그대로** 올라갑니다.
- PEM에서 chain을 선택하면 `{이름}_fullchain.pem`(인증서 + chain)을 자동으로 만들어 함께 올립니다. chain 파일 자체는 올리지 않습니다.
  - 예: `www.example.com_cert.pem` → 서버에 `www.example.com_cert.pem`, `www.example.com_key.pem`, `www.example.com_fullchain.pem`
- 카드에 인증서 파일의 만료일과 D-Day가 표시됩니다 (PKCS12 형식 jks는 비밀번호 없이 읽을 수 없어 표시하지 않음).

nginx 설정 예:
```nginx
ssl_certificate     /etc/nginx/ssl/www.example.com_fullchain.pem;
ssl_certificate_key /etc/nginx/ssl/www.example.com_key.pem;
```

### 3. 배포
1. 인증서 카드에서 **[배포…]** 를 누릅니다.
2. 배포할 서버를 체크합니다. 인증서 형식과 맞지 않는 서버는 선택할 수 없습니다.
3. 배포 전에 키 짝, 만료 여부, 도메인 일치 여부를 검사합니다.
4. 서버마다 기존 파일을 백업한 뒤 한꺼번에 교체하고 재시작 명령을 실행합니다. 교체에 실패하면 자동으로 되돌립니다.
5. 한 서버가 실패해도 나머지 서버는 계속 배포되며, 서버별 결과가 표시됩니다. 비밀번호 오류는 그 서버만 다시 시도할 수 있습니다.

### 4. 대시보드
- 모니터링할 도메인을 추가하면 각 도메인의 443 포트에 접속해 **서버에 실제 적용된** 인증서의 만료일, D-Day, 상태(정상/만료 임박/만료)를 보여 줍니다.
- 앱을 시작할 때 전체를 한 번 확인합니다.

### 5. 설정
- **Slack Webhook**: 배포 결과와 만료 임박 알림을 보냅니다.
- **내보내기/가져오기**: 설정 전체(서버, 키, 저장된 비밀번호 포함)를 비밀번호로 암호화한 `.sslm` 파일로 옮깁니다. 가져오면 기존 설정은 백업 후 교체됩니다.
- **업데이트**: 현재 버전을 확인하고 수동으로 업데이트를 확인·설치할 수 있습니다.

## 업데이트
- 설치형은 앱을 시작할 때 새 버전을 확인하고 백그라운드에서 내려받습니다. 준비되면 상단 안내의 **[재시작해서 설치]** 를 누르거나, 앱을 종료할 때 자동으로 설치됩니다.
- 배포가 진행 중일 때는 재시작 설치가 막힙니다.
- 1.0.0에는 업데이트 기능이 없으므로 1.0.0 사용자는 다음 버전을 한 번 직접 설치해야 합니다.

## 데이터 위치
설정은 `%APPDATA%\ssl-manager\config.ini.enc`에 Windows 계정 기준으로 암호화되어 저장됩니다. 다른 PC나 다른 계정으로 옮길 때는 설정 내보내기/가져오기를 사용하세요.
